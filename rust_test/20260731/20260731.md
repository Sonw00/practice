# rust 코딩 테스트

### 1. Hello World

단순히 **”Hello, World!”**를 반환 하는 문제입니다.

```rust
// &'static is a "lifetime specifier", something you'll learn more about later
pub fn hello() -> &'static str {
    "Hello, World!"
}

```

`&'static str` 은 프로그램이 실행되는 내내 메모리에 유지되는 문자열 참조입니다. 

라이프 타임: 특정한 참조자가 특정한 시간에 유효할 것을 보장하기 위해 사용하며 댕글링 레퍼런스(메모리에서 해제된 변수를 사용하는 경우) 문제를 해결할 수 있습니다.
