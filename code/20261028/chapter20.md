20장에서는 덧셈, 뺄셈과 같은 연산을 자동화할 수 있다고 소개합니다. 17장에서 구현했던 8비트 가산기는 더하기 신호를 1로 바꿀 때마다 8비트 래치에 8비트 누적값이 저장됩니다. 만약 값을 누적하는 중에 숫자를 잘못 입력했다면 처음부터 다시 입력해야 하는 문제가 있습니다. 

대신에 64kB RAM 어레이를 이용해서 누산 작업을 처리할 수 있습니다. 
1. 더하고자 하는 8바이트 숫자를 RAM 어레이의 첫번째 주소 0000h 부터 하나씩 할당합니다. 
2. 8비트 가산기를 64k x 8 RAM과 연결하면 특정 주소값을 가산기에서 누적하고 누적한 값을 메모리 주소에 다시 저장할 수 있습니다.
3. 16비트 카운터를 64k x 8 RAM의 주소 입력으로 연결하면 첫번째 주소 0000h 부터 순차적으로 순회할 수 있습니다.
