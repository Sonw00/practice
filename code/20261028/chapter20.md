20장에서는 덧셈, 뺄셈과 같은 연산을 자동화할 수 있다고 소개합니다. 17장에서 구현했던 8비트 가산기는 더하기 신호를 1로 바꿀 때마다 8비트 래치에 8비트 누적값이 저장됩니다. 만약 값을 누적하는 중에 숫자를 잘못 입력했다면 처음부터 다시 입력해야 하는 문제가 있습니다. 

대신에 64kB RAM 어레이를 이용해서 누산 작업을 처리할 수 있습니다. 

1. 더하고자 하는 8바이트 숫자들을 RAM 어레이의 첫 번째 주소 0000h부터 하나씩 할당합니다. 
2. 64k x 8 RAM에 8비트 가산기를 연결하면 특정 주솟값을 가산기에서 누적하고 누적한 값을 메모리 주소에 다시 저장할 수 있습니다.
3. 16비트 카운터를 64k x 8 RAM의 주소 입력으로 연결하면 첫 번째 주소 0000h부터 순차적으로 순회할 수 있습니다.
4. 16비트 카운터와 8비트 가산기의 클럭 신호를 번갈아 가면서 신호를 주게 되면 주소를 순차적으로 순회하면서 값을 누적하게 됩니다.
5. 8비트 가산기의 클럭 입력에 신호를 주면 메모리 셀에 누적값이 저장됩니다. 본문 384 페이지 회로에서는 메모리 셀에 값이 비어있을 때 누적값을 쓰도록 동작합니다. 값을 누적할 때에는 RAM에 주소가 설정된 후 안정화된 상태여야 합니다.
6. 누적값과 메모리 주소를 초기화하는 지우기 버튼을 추가합니다.

8비트 가산기는 8비트 범위만 누적할 수 있기 때문에 누적값이 십진수로 255가 넘어가면 9번째 비트 자리올림값은 버려지는 문제가 있습니다. 더 큰 값을 저장하려면 더 많은 바이트를 다룰 수 있는 RAM 어레이와 가산기를 사용해야 하고 뺄셈을 계산하려면 2의 보수(비트 반전하고 +1)를 사용하면 됩니다. 더 큰 값을 다루기 위해 RAM 어레이 내부 구조를 뜯어 고쳐서 메모리 셀을 확장할 수도 있지만 그 대신에 연속된 메모리에 값을 분할해서 더 큰 값을 저장할 수 있습니다. 데이터의 가장 높은 바이트부터 낮은 메모리 주소에 저장하는 **빅 엔디언** 방식과 데이터의 가장 낮은 바이트부터 순서대로 저장하는 **리틀 엔디언** 방식 모두 사용됩니다.
