3바이트 누산기는 4바이트씩 순회하는데 첫 번째 바이트는 명령어 코드로 읽고 나머지 세 바이트는 명령어 코드에 해당하는 동작(덧셈, 뺄셈, 저장, 종료)을 수행하는 데 사용합니다. 메모리 주소 최하위 2자리로 어느 위치를 나타내는 바이트인지 확인할 수 있습니다. 최하위 비트 2자리가 00이면 명령어 코드가 저장되는 위치이므로 명령어 래치에 값을 저장합니다. 01이면 낮은 래치에 저장된 값과 명령어 코드에 해당하는 연산을 수행하고 연산 결과를 다시 낮은 래치에 저장합니다. 10이면 중간 래치에 저장하고 11이면 높은 래치에 값을 저장합니다. 명령어 코드가 저장이면 래치에 저장한 연산 값을 메모리에 쓰고 명령어 코드가 종료면 누산기 동작을 멈춥니다.
