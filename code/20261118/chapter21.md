- 416p 중간: ASCII문자를 20h와 OR 연산하면 6번째 비트가 1이 되므로 소문자로 변환됩니다. 
- 417p 1/3 지점: 비트 단위 OR연산 방식을 활용해서 두 8바이트 입력에 대해 같은 자릿수끼리 OR연산을 처리하는 회로를 ALU에 추가합니다.
- 418p: ASCII 문자를 대문자로 바꾸려면 6번째 자릿수를 0으로 바꾸면 되므로 문자를 DFh와 AND연산하면 됩니다.
- 419p: 비트 단위 AND연산 방식을 활용해서 두 8바이트 입력에 대해 같은 자릿수끼리 AND연산을 처리하는 회로를 ALU에 추가합니다.
- 419p 마지막: 두 8바이트 입력에 대해 같은 자릿수끼리 OR 연산을 처리하는 회로를 ALU에 추가합니다. OR연산을 이용해서 원하는 비트를 반전시킬 수 있습니다.
- 420p 마지막: ALU에 기능 비트를 하나 추가해서 비트 단위 AND, XOR, OR 이외에 비교 동작까지 처리할 수 있도록 합니다.
- 421p 중간: 명령어 다음으로 나오는 바이트를 연산으로 사용하는 즉치 명령어도 있습니다.
- 422p: 기능 비트 3개를 이용해서 AND, XOR, OR 연산중에 하나를 지정해서 처리하도록 하기 위해 3개 회로에 삼상 버퍼를 연결하고 기능 비트에 대응하는 회로에 연결된 삼상버퍼만 신호가 흐르게 합니다.
- 422p 마지막: 두 숫자중에서 어떤 값이 큰지 판단하기 위해 두 숫자끼리 뺄셈한 결과로 판단할 수 있습니다. 뺄셈 결과를 확인하려면 결과가 0인지 확인하는 제로 플래그와 연산 결과의 부호 비트가 1인지 0인지 판단하는 부호 플래그 두가지가 필요합니다.
- 424p: 산술 회로와 논리 회로를 결합해서 산술 논리 장치 ALU를 만듭니다.
