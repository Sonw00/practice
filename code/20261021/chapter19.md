8개 플립플롭에서 나오는 데이터 출력을 8-to-1 선택기의 입력으로 연결하면 주소(3비트 선택) 신호에 해당하는 플립플롭에 저장된 값이 8-to-1 선택기의 데이터 출력으로 표시됩니다. 메모리 주소를 지정하고 원하는 시점에 메모리 쓰기 동작을 수행한 것입니다. 주소 신호를 변경하면 해당 주소에 저장된 메모리값이 출력됩니다. 메모리 쓰기 동작을 수행하고 원하는 시점에 특정 메모리 값을 확인하는 장치를 RAM이라고 부릅니다. 진공관과 트랜지스터가 발명되기 전 1960년대 후반까지는 메모리에 수은관을 사용하곤 했는데 이 방식은 신호가 전달되는데 지연이 존재했습니다.

8비트를 저장하는 RAM을 기호로 표시할 때 RAM 어레이 방식으로 간단하게 표시할 수 있습니다. 직전에 1비트 크기 값을 8개 메모리에 저장했기 때문에 짧게 8X1 RAM 어레이라고 부를 수 있습니다.











4-to-16 디코더를 사용하면 4비트를 이용해서 16개 메모리중 하나를 지정해서 값을 쓸 수 있습니다. 16개 메모리에서 나오는 16개 DO 출력을 16-to-1 선택기 입력으로 연결하면 선택한 메모리 값이 출력됩니다.
