8개 플립플롭에서 나오는 데이터 출력을 8-to-1 선택기의 입력으로 연결하면 주소(3비트 선택) 신호에 해당하는 플립플롭에 저장된 값이 8-to-1 선택기의 데이터 출력으로 표시됩니다. 메모리 주소를 지정하고 원하는 시점에 메모리 쓰기 동작을 수행한 것입니다. 주소 신호를 변경하면 해당 주소에 저장된 메모리값이 출력됩니다. 메모리 쓰기 동작을 수행하고 원하는 시점에 특정 메모리값을 확인하는 장치를 RAM이라고 부릅니다. 진공관과 트랜지스터가 발명되기 전 1960년대 후반까지는 메모리에 수은 관을 사용하곤 했는데 이 방식은 신호가 전달되는데 지연이 존재했습니다.

8비트를 저장하는 RAM을 기호로 표시할 때 RAM 어레이 방식으로 간단하게 표시할 수 있습니다. 1비트 크기 값을 8개 메모리에 저장하는 RAM 어레이를 짧게 8X1 RAM 어레이라고 부를 수 있습니다. RAM 어레이 여러 개를 연결해서 데이터 입력과 데이터 출력 폭을 늘리거나 메모리 개수를 추가할 수도 있습니다. RAM 어레이에 저장할 수 있는 총 비트 수는 메모리 수 X 데이터 폭 개수와 같습니다. 16바이트를 저장하려면 데이터 크기 8을 저장할 수 있는 메모리 16개가 있어야 합니다. 

4-to-16 디코더를 사용하면 4비트를 이용해서 16개 메모리 중 하나를 지정해서 값을 쓸 수 있습니다. 16개 메모리에서 나오는 16개 DO 출력을 16-to-1 선택기 입력으로 연결하면 선택한 메모리 값이 출력됩니다. 각 메모리의 DO 신호를 트랜지스터에 연결하고 4-to-16 디코더 출력 신호를 베이스로 연결하면 선택한 주소의 메모리 데이터 출력만 1을 가질 수 있게 됩니다. 전류는 컬렉터에서 이미터로만 흐르기 때문에 트랜지스터가 연결된 데이터 출력을 직접 연결해도 합선이 발생하지 않습니다. 이처럼 허용 신호를 통해 출력을 제어하는 트랜지스터를 삼상 버퍼라고 부릅니다. 362 페이지 상단 회로에서 DO<small>1</small>~DO<small>16</small> 에 각각 삼상 버퍼를 추가로 연결하고 허용 신호를 연결함으로써 16X8 메모리 어레이 자체에 대한 허용 입력을 구현할 수 있습니다. 여기서 말하는 허용의 의미는 플립플롭 값 저장에 대한 허용이 아닌 값 출력에 대한 허용을 의미하는 것으로 보입니다.

16 X 8 RAM 어레이 16개를 이어 붙이고 주소 입력을 8비트로 받도록 수정하면 256 X 8 RAM 어레이를 만들 수 있고 256 X 8 RAM 어레이 16개를 이어붙여서 4096X8 RAM 어레이를 만들 수 있고 4096개의 RAM을 제어하기 위해 12비트 주소가 필요합니다. 2에서 주소 비트수만큼 제곱한 갯수만큼 RAM에 값을 저장할 수 있습니다.

저장 단위는 2의 거듭 제곱 단위로 처리합니다. 무게나 길이 단위에서 킬로는 1000을 의미하지만  1kB(킬로바이트)는 2의 10제곱인 1024 바이트입니다. 64kB는 64 x $2^{10}$ = 65536 바이트입니다. 1MB는 $2^{20}$바이트와 같고 100만에 근사합니다. 1GB는 $2^{30}$바이트와 같고 10억에 근사합니다. 그 다음으로 2의 10제곱씩 바이트 단위가 커질 때마다 테라바이트, 페타바이트, 엑사바이트를 사용합니다. 

플립플롭으로 구성했던 메모리는 SRAM입니다. DRAM은 각 메모리 셀이 트랜지스터와 커패시터로 구성되어있고 이것으로 전하를 저장할 수 있습니다.
