### Chapter 6 논리와 스위치

아리스토텔레스 논리학에서 기본이 되는 것은 연역법이라 불리는 삼단 논법입니다. 삼단 논법에서는 두 개의 전제가 참이라면 결론도 참으로 추론됩니다. 아리스토텔레스 논리학을 수학 기호와 연산자를 이용하여 표현하기 위해 불 대수가 발명되었습니다.

불 대수에서 `+` 또는 `∪` 기호는 두 종류의 합집합 union을 의미하고 `X` 또는 `∩`기호는 두 종류의 교집합 intersection을 의미합니다. `-` 기호는 차집합을 의미하고 `1`은 전체 집합 universe, `0`은 공집합 empty set 이라고 부릅니다.

만약 수컷 고양이 집합을 M 이라 표현하고 중성화한 고양이를 N 이라고 부른다면 중성화한 수컷 고양이를 불 대수에서 M∩N 로 표현할 수 있습니다. 암컷 고양이가 F 라면 MXF=0 이고 M+F=1입니다.

만약 애완동물 가게의 손님이 다음과 같은 고양이를 원한다고 가정합니다. "중성화된 수컷 고양이인데, 흰색이나 황갈색이면 좋겠어요. 아니면 중성화된 암컷 고양이에 흰색만 아니면 괜찮을 것 같아요. 검은색 고양이라면 어떤 고양이든 괜찮아요." 검은색 고양이를 B, 황갈색 고양이를 T, 흰색 고양이를 W라고 부른다면 손님의 요구사항을 불 대수로 표현하면 다음과 같습니다.

(MXNX(W+T))+(FXNX(not W))+B

만약 어떠한 고양이가 요구 사항에 부합하는지 확인하기 위해 논리 검사 Boolean test 를 수행할 수 있습니다. 예를 들어 중성화되지 않은 수컷 황갈색 고양이가 적합한 고양이인지 확인하기 위해 수식에서 조건에 만족하는지에 따라 0과 1을 대입하면 됩니다.

(1X0X(0+1))+(0X0X(not 0))+0 = 0

불 대수를 전자 회로와 결합시켜서 이진수 기반으로 부합하는지 검사할 수 있습니다. AND 연산 결과가 참이기 위해서는 두 값이 모두 참이어야 하기 때문에 직렬로 연결해야 하고 OR 연산은 두 값중 하나라도 참이어야 하기 때문에 병렬로 연결해야 합니다.
