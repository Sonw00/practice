컴퓨터는 크게 메모리, CPU, 입출력 장치로 구성되어 있는데 19장과 20장에서는 메모리를 어떻게 다루는지 확인했습니다. 컴퓨터 종류에 따라 여러가지 입출력 장치와 저장 장치가 사용됩니다.

CPU는 20장에서 확인했던 3바이트 누산기보다 더 다양한 작업을 수행합니다. 8비트 CPU는 바이트 단위로 동작하지만 16비트 메모리 주소를 처리할 수 있으며, 다양한 산술, 논리 작업을 처리할 수 있습니다. 최신 16, 32, 64비트 CPU는 8비트 CPU보다 같은 작업을 더 빠르게 처리합니다. 

8비트 CPU로 두 개의 16비트 숫자를 더할 수 있도록 메모리에 명령어 코드와 데이터의 조합으로 입력할 수 있습니다.
