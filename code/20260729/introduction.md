### 옮긴이의 글

프로세서의 동작을 잘 알 수록 운영체제나 컴파일러와 같은 시스템 프로그램뿐만 아니라 응용 프로그램에서도 프로세서를 더욱 효율적으로 사용할 수 있습니다. 이 책에서는 어떻게 디지털 논리 회로를 통해 연산기가 동작하는지부터 시작해서 어떻게 프로세서를 제어하고 데이터 처리로 바꿀 수 있는지, 주변 장치와 어떻게 상호작용을 할 수 있는지를 포괄적으로 다룹니다. 기술적으로 자세한 부분을 모두 이해하지 못하더라도 프로세서 하드웨어 위에 소프트웨어가 올라가고 동작하는 방식을 이해하는 것이 중요합니다.
