컴퓨터는 메모리, CPU, 입출력 장치를 이용해서 문서, 사진, 음악, 동영상과 같은 디지털 데이터를 다루고 저장할 수 있습니다. CPU 동작에 대해 설명하는 것으로 가장 먼저 8비트 단위로 처리하는 CPU를 활용해서 16비트 숫자를 더하는 과정을 설명합니다. 명령어 코드를 이용해서 낮은 바이트와 높은 바이트끼리 더하고 원하는 메모리 주소 위치에 값을 저장합니다. 

ALU는 CPU에서 덧셈, 뺄셈과 같은 연산을 처리하는 것을 담당합니다. 여러 바이트 숫자끼리 덧셈, 뺄셈하기 위해 우선 최하위 바이트는 그냥 더하거나 빼고 그 다음 바이트부터는 자리 올림까지 처리해야 합니다. 자리 올림과 빌림을 처리할 수 있는 덧셈/뺄셈을 회로로 표시할 때 동작은 F0, F1 입력으로 제어합니다.
