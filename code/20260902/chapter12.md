## Chapter12 바이트와 16진수

컴퓨터에서는 여러 비트를 이용해서 문자, 소리, 음악, 사진, 영상 등의 데이터를 다루는데 사용합니다. 

초기의 일부 컴퓨터에서는 데이터를 다루기 위한 비트 묶음을 6의 배수로 사용하기도 했지만, 이진수의 중요성이 점차 부각되면서 8비트로 구성된 바이트를 디지털 데이터의 보편적인 단위로 사용하게 됩니다. 8비트는 256가지의 경우의 수를 표현할 수 있는데, 이 경우의 수는 전세계 문자를 다루거나 색상값을 표현하는 것에 이상적으로 사용됩니다. 1970년대 개인용 컴퓨터가 보급되기 시작할 때는 상당수 컴퓨터가 8비트를 사용했고 기술이 발전하면서 16비트, 32비트, 64비트로 각각 늘어납니다 바이트의 절반인 4바이트 단위를 **니블 nibble**이라고 부릅니다.

이진수를 열형태로 나열하는 것보다는 바이트 단위로 나누어서 표시하는 것이 더 간결하고 바이트를 절반으로 나눈 2개의 4비트 묶음을 각각 **16진수**로 변환하여 더욱 간결하게 표시할 수 있습니다.

**16진수 hexadecimal**는 0 ~ 9, A ~ F 까지 16개의 기호를 사용합니다. 아라비아 숫자에서는 0부터 9까지 10개의 숫자 기호만 사용하기 때문에 10부터 15까지 숫자를 기호로 표현하기 위해 A ~ F 알파벳을 사용한 것입니다. 16진수를 표시할 때 10진수와 구분하기 위해 숫자 뒤에 'h'를 붙입니다. 

HTML에서 색상값을 # 기호와 16진수 6자리로 표현합니다. 앞에서부터 16진수 두자리씩 RGB값을 나타냅니다. 컴퓨터 화면에서 이미지를 저장하기 위해 사용되는 바이트 수는 픽셀 수(가로X세로) X 256 X 256 X 256 입니다.

16진수에서도 n번째 자리가 차지하는 크기는 십진수로 표현하면 $16^{n-1}$ 입니다. 16진수를 10진수로 변환하려면 각 자리 숫자를 자릿수 크기만큼 곱하고 각각 합산하면 됩니다. 10진수를 16진수로 변환하려면 16의 거듭제곱으로 나누어지는 몫을 큰 숫자부터 나열하면 됩니다. 10진수를 나눈 몫이 16 미만일 때까지 나누는 값을 16씩 거듭제곱합니다.
