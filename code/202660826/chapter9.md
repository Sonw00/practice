우리는 현재 숫자를 표현하기 위해 10진법의 아라비아 숫자 체계를 사용합니다.

아직 사용되는 로마 숫자 쳬계에서는 I(1), V(5), X(10), L(50), C(100), D(500), M(1000) 단위로 표현하지만 연산하는데 매우 복잡한 방법을 사용해야 하는 불편이 있습니다.

초기에 사용되었던 다른 숫자 체계와 다르게, 아라비아 숫자는 차이가 있습니다.
- 십을 나타내기 위한 기호를 별도로 사용하지 않고 자릿수로 표현합니다.
- 0을 사용합니다.

0을 사용하게 되면서 각 자릿수를 구별할 수 있게 되었고 숫자 연산을 쉽게 처리할 수 있게 되었습니다.

10진법의 n번째 자릿수는 $10^{n-1}$ 크기를 나타내고 소수점 n번째 자릿수는 $10^{-n}$ 크기를 나타냅니다.
