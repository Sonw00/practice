최대 개수: $ARGUMENTS (비어 있으면 20)

CLAUDE.md의 "복습 간격"을 따른다.

## 1. 출제 대상 고르기

- `vocab.md`와 `grammar.md`에서 상자가 1~5이고 `다음 복습`이 오늘 이전(오늘 포함)인 행을 모은다.
- 정렬: 다음 복습이 오래된 순 → 오답이 많은 순.
- 최대 개수만큼 자른다. 단어와 문법이 모두 있으면 문법이 전체의 1/4 정도 되도록 섞는다.
- 대상이 없으면 "오늘 복습할 항목이 없습니다"와 가장 가까운 다음 복습일을 알려주고 끝낸다.
- 시작 전에 "오늘 복습: 단어 N개, 문법 M개"를 보여준다.

## 2. 출제 방식

**한 번에 한 문제씩** 내고 사용자의 답을 기다린다. 정답은 미리 보여주지 않는다.

단어는 상자 번호에 따라 유형을 정한다. 상자가 올라갈수록 알아보기에서 직접 쓰기로 난도가 오른다.

| 유형 | 사용 상자 | 형식 |
|---|---|---|
| A. 빈칸 채우기 | 1, 2 | 원문 예문에서 단어를 `____`로 가리고 한국어 뜻과 첫 글자를 힌트로 준다 |
| B. 뜻 말하기 | 3 | 원문 예문을 그대로 보여주고 기울임 단어의 뜻을 묻는다 |
| C. 영작 | 4, 5 | 한국어 문장을 주고 그 단어를 써서 영어로 옮기게 한다. 원문과 다른 새 문장으로 낸다 |

문법은 패턴 이름과 원문 예문을 보여주고, **그 패턴으로 업무 상황 문장을 하나 쓰게** 한다.

## 3. 채점

- 정답(O) / 오답(X)으로 판정하고 한두 줄로 이유를 말한다.
- 유형 A: 시제·수 변화는 정답으로 인정한다. 철자가 한 글자 틀리면 정답으로 하되 올바른 철자를 알려준다.
- 유형 B: 문맥상 뜻이 맞으면 정답.
- 유형 C와 문법: 목표 단어나 패턴을 올바르게 썼으면 다른 부분의 사소한 실수가 있어도 정답이다. 대신 더 자연스러운 문장을 함께 제시한다.
- 사용자가 `모름` 또는 `pass`라고 하면 오답으로 처리하고 정답을 알려준다.
- 사용자가 `정정`이라고 하면 직전 판정을 뒤집는다.

## 4. 기록 (매 문제 직후)

중간에 멈춰도 진도가 남도록 **한 문제 채점이 끝날 때마다** 파일을 수정한다.

- 정답: 상자 +1, 다음 복습 = 오늘 + 새 상자의 간격. 상자 5에서 정답이면 상자 `✓`, 다음 복습 `-`.
- 오답: 상자 1, 다음 복습 = 내일, 오답 +1.
- 문법에서 정답이면 `내가 만든 문장` 열을 사용자가 쓴 문장(교정본)으로 갱신한다.

## 5. 마무리

모든 문제가 끝나면 다음을 보여준다.

```
### 오늘 복습 결과
- 정답 N / 전체 M
- 졸업: word1, word2
- 다시 상자 1로: word3, word4
- 다음 복습 예정: 내일 K개
```

그리고 커밋 명령을 제안한다. 사용자가 승인하면 실행한다.

```
git add . && git commit -m "Review YYYY-MM-DD: N of M correct"
```
