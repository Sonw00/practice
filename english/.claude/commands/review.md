인자: $ARGUMENTS

- 숫자는 최대 개수다. 없으면 20.
- `뜻`, `빈칸`, `영작` 중 하나가 있으면 모든 단어 문제를 상자와 관계없이 그 유형으로 낸다. 없으면 상자 번호로 정한다.

CLAUDE.md의 "복습 간격"을 따른다.

## 1. 출제 대상 고르기

- `vocab.md`와 `grammar.md`에서 상자가 1~5이고 `다음 복습`이 오늘 이전(오늘 포함)인 행을 모은다.
- 정렬: 다음 복습이 오래된 순 → 오답이 많은 순.
- 최대 개수만큼 자른다. 단어와 문법이 모두 있으면 문법이 전체의 1/4 정도 되도록 섞는다.
- 대상이 없으면 "오늘 복습할 항목이 없습니다"와 가장 가까운 다음 복습일을 알려주고 끝낸다.
- 시작 전에 "오늘 복습: 단어 N개, 문법 M개"를 보여준다.

## 2. 출제 방식

**한 번에 한 문제씩** 내고 사용자의 답을 기다린다. 정답은 미리 보여주지 않는다. 문제 번호(예: `3/15`)를 함께 보여준다.

단어는 상자 번호에 따라 유형을 정한다. 먼저 뜻을 확실히 익히고, 상자가 올라가면 토익 문제 형태로 쓰임을 확인한 뒤 직접 써 보는 단계로 넘어간다.

| 유형 | 사용 상자 | 형식 |
|---|---|---|
| 뜻 말하기 | 1, 2 | 원문 예문을 그대로 보여주고 기울임 단어의 뜻을 한국어로 묻는다. 품사나 첫 글자 힌트는 주지 않는다 |
| 빈칸 채우기 | 3 | 토익 Part 5 형식. 원문과 다른 업무 상황 문장에서 단어 자리를 `-------`로 비우고 보기 (A)~(D) 중 하나를 고르게 한다 |
| 영작 | 4, 5 | 업무 상황의 한국어 문장을 주고 그 단어를 써서 영어로 옮기게 한다. 원문과 다른 새 문장으로 낸다 |

- 업무 상황은 토익에 자주 나오는 회의, 출장, 주문·배송, 채용·인사, 사내 공지, 고객 응대 등에서 고른다.
- 빈칸 채우기의 보기는 정답 1개와 오답 3개다. 오답은 정답의 다른 품사형(`addictive` → `addict`, `addiction`, `addictively`)이나 뜻·철자가 비슷한 단어로 만든다. 숙어·구동사는 전치사나 부사만 다른 형태(`go through` → `go over`, `go by`)를 쓴다. 정답이 하나뿐인 문장으로 만들고, 정답 위치는 매번 바꾼다.

문법은 패턴 이름과 원문 예문을 보여주고, **그 패턴으로 업무 상황 문장을 하나 쓰게** 한다.

## 3. 채점

- 정답(O) / 오답(X)으로 판정하고 한두 줄로 이유를 말한다.
- 뜻 말하기: 문맥에 맞는 핵심 뜻을 말하면 정답이다. 뜻이 여러 개인 단어는 문맥에 맞는 뜻 하나면 된다.
- 빈칸 채우기: 기호나 단어로 답해도 된다. 채점 뒤에 오답 보기가 왜 틀렸는지 한 줄로 설명한다.
- 영작과 문법: 목표 단어나 패턴을 올바르게 썼으면 다른 부분의 사소한 실수가 있어도 정답이다. 대신 더 자연스러운 문장을 함께 제시한다. 목표 단어의 시제·수 변화는 인정하고, 철자가 한 글자 틀리면 정답으로 하되 올바른 철자를 알려준다.
- 단어 문제는 채점 뒤에 `토익 포인트` 한 줄을 붙인다. 품사 변화(파생어)와 토익에 자주 나오는 동의어·짝 표현을 적고, 해당하는 것이 없으면 생략한다.
- 사용자가 `모름` 또는 `pass`라고 하면 오답으로 처리하고 정답을 알려준다.
- 사용자가 `정정`이라고 하면 직전 판정을 뒤집는다.
- 사용자가 `그만`이라고 하면 남은 문제를 내지 않고 5절로 넘어간다.

## 4. 기록 (매 문제 직후)

중간에 멈춰도 진도가 남도록 **한 문제 채점이 끝날 때마다** 파일을 수정한다.

- 정답: 상자 +1, 다음 복습 = 오늘 + 새 상자의 간격. 상자 5에서 정답이면 상자 `✓`, 다음 복습 `-`.
- 오답: 상자 1, 다음 복습 = 내일, 오답 +1.
- 문법에서 정답이면 `내가 만든 문장` 열을 사용자가 쓴 문장(교정본)으로 갱신한다.

## 5. 마무리

모든 문제가 끝나면 다음을 보여준다.

```
### 오늘 복습 결과
- 정답 N / 전체 M
- 졸업: word1, word2
- 다시 상자 1로: word3, word4
- 다음 복습 예정: 내일 K개
```

그리고 커밋 명령을 제안한다. 사용자가 승인하면 실행한다.

```
git add . && git commit -m "Review YYYY-MM-DD: N of M correct"
```
