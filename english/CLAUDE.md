# 영어 학습 디렉터리

업무 중 읽는 영어 웹 문서로 영어를 공부하는 공간이다. 응답은 항상 **한국어**로 한다.

## 파일 구성

| 경로 | 용도 |
|---|---|
| `articles/` | 읽은 문서의 원문과 해석 (`YYYY-MM-DD-<slug>.md`) |
| `vocab.md` | 단어장. 실제로 몰랐던 단어, 숙어, 구동사 |
| `grammar.md` | 문법·표현 패턴 |
| `known.md` | 이미 아는 단어. 여기 있는 단어는 다시 후보로 뽑지 않는다 |
| `weekly/` | 주간 작문·통계 기록 (`YYYY-Www.md`) |

## 명령어

절차는 `commands/` 폴더의 파일에 있다. 사용자가 아래 명령을 입력하면 (앞의 `/`는 있어도 되고 없어도 된다) 해당 파일을 읽고 그 절차를 그대로 따른다. 파일 안의 `$ARGUMENTS`는 명령 뒤에 입력한 내용이다.

| 입력 | 절차 파일 | 하는 일 |
|---|---|---|
| `read <URL 또는 본문>` | `commands/read.md` | 문장별 해석, 단어·문법 후보 추출 |
| `review [개수]` | `commands/review.md` | 오늘 복습할 항목 출제·채점 |
| `weekly [첨삭받을 문장]` | `commands/weekly.md` | 이번 주 단어로 영작, 주간 통계 |

명령 없이 영어 본문이나 URL만 붙여넣어도 `read`와 똑같이 처리한다.

`commands/` 폴더를 `.claude/commands/`로 복사하면 `/read`, `/review`, `/weekly`가 Claude Code 슬래시 명령어로도 등록된다.

## 후보 선택 응답 처리

`read`가 끝나면 사용자는 아래 형식으로 실제로 몰랐던 항목을 고른다.

- `W 3,5,9 G 2`: 단어 W3, W5, W9와 문법 G2를 저장한다.
- `W all`, `G all`: 해당 종류의 후보를 모두 저장한다.
- `없음`: 저장하지 않는다.

처리 규칙은 다음과 같다.

1. 선택한 W 항목은 `vocab.md`에, G 항목은 `grammar.md`에 한 행씩 추가한다.
2. **선택하지 않은 W 후보**는 `known.md`에 추가한다. 선택하지 않은 G 후보는 어디에도 기록하지 않는다.
3. 이미 `vocab.md`에 있는 단어를 다시 선택하면 새 행을 만들지 않는다. 기존 행을 상자 1, 다음 복습 내일로 되돌리고 오답을 +1 한다. `(복습 중)`으로 표시된 단어를 사용자가 "몰랐다"고 하면 같은 방식으로 처리한다.
4. 처리 후 추가한 항목과 known.md로 보낸 단어를 짧게 요약해 보여준다.

## 기록 형식

### vocab.md

| 열 | 규칙 |
|---|---|
| 단어 | 원형으로 적는다. 숙어·구동사는 구 전체를 적는다 (`rule out`) |
| 뜻 | 원문 문맥에 맞는 한국어 뜻. 품사 약어를 앞에 붙인다 (`v. 완화하다`) |
| 원문 예문 | 문서에 나온 문장을 **그대로** 적고, 해당 단어는 `*기울임*`으로 표시한다 |
| 출처 | `[문서 제목](articles/파일명.md)` |
| 추가일 | `YYYY-MM-DD` |
| 상자 | 1~5, 졸업하면 `✓` |
| 다음 복습 | `YYYY-MM-DD`, 졸업하면 `-` |
| 오답 | 틀린 누적 횟수 |

### grammar.md

`패턴 | 설명 | 원문 예문 | 내가 만든 문장 | 출처 | 추가일 | 상자 | 다음 복습 | 오답`

- 패턴은 `분사구문 (-ing, S V)`처럼 이름과 형태를 함께 적는다.
- `내가 만든 문장`은 복습에서 사용자가 쓴 문장 중 가장 최근에 맞은 문장으로 갱신한다. 처음에는 비워 둔다.

### known.md

`- word` 형식으로 한 줄에 한 단어씩 적는다.

### 공통 규칙

- 표 셀 안의 `|` 문자는 `\|`로 이스케이프한다.
- 새 항목은 상자 1, 다음 복습은 추가일 다음 날로 둔다.
- 날짜는 현재 시스템 날짜(Asia/Seoul) 기준이다.

## 복습 간격 (Leitner)

| 상자 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 맞히고 이 상자로 이동했을 때 다음 복습 | 1일 후 | 3일 후 | 7일 후 | 14일 후 | 30일 후 |

- 맞히면 상자 +1. 상자 5에서 맞히면 졸업(`✓`, 다음 복습 `-`).
- 틀리면 상자 1, 다음 복습은 내일, 오답 +1.

## 후보 선정 기준

단어 후보로 뽑는 것:

- 중급 수준 학습자에게 생소할 만한 일반 어휘, 숙어, 구동사, 기술 문서에 자주 나오는 격식체 표현 (`leverage`, `mitigate`, `in lieu of`, `rule out`)
- 쉬운 단어라도 문맥상 특수한 뜻으로 쓰인 경우 (`address` = 해결하다)

뽑지 않는 것:

- `known.md`에 있는 단어
- 한국 개발자가 영어 그대로 쓰는 기술 용어 (thread, runtime, commit, deploy 등)
- 코드 블록, 식별자, 명령어, 고유명사

이미 `vocab.md`에 있는 단어가 나오면 번호를 붙이지 않고 `(복습 중)`으로 표시해서 다시 보게만 한다.

문법 후보로 뽑는 것: 분사구문, 관계사 생략, 가정법, 도치, 강조 구문, 동격, 긴 명사구 수식, 해석이 헷갈리는 수동태·전치사 결합 등 **문장 구조를 이해하는 데 걸림돌이 될 만한 것**.

## git

- 기록 파일을 수정한 뒤에는 커밋 명령을 제안만 하고, 사용자가 승인하면 실행한다.
- 커밋 메시지는 영어 한 문장으로 쓴다 (예: `Add 6 words from Tokio runtime docs`).
